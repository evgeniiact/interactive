Просите ИИ назвать не только варианты, но и вопросы для выбора. Тогда ответ станет основой для разговора с администрацией, а не набором общих советов.
Работаем с тем же проектом по сбору батареек. Известно: - контейнер нужен для сотрудников административного корпуса, около 50 человек; - планируется принимать только обычные бытовые батарейки; - точной оценки объема сбора пока нет; - планируется один контейнер; - предполагаемое место - фойе у стойки администратора; - за проект отвечает эколог; - ответственный за ежедневный контроль пока не назначен; - договора с подрядчиком пока нет. Предложи варианты для обсуждения с администрацией. Сравни: - место размещения контейнера; - формат контейнера с учетом неизвестного объема сбора; - порядок контроля его состояния; - действия при заполнении. Для каждого варианта укажи: - преимущества; - ограничения; - что нужно уточнить перед выбором. Отдельно составь список вопросов, которые нельзя решать по общему ответу. Для каждого укажи, где его проверить: во внутренних документах, у администрации, в договоре, у подрядчика или в действующих нормативных актах. Представь результат в таблице. Не выбирай вариант вместо меня.
