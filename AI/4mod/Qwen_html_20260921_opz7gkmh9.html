1 Создайте проект
Создайте отдельный проект для повторяющейся задачи. Дайте проекту понятное название. По названию должно быть ясно, какие материалы и чаты здесь хранятся.
Пример
Памятки и инструктажи
Внимание
Не называйте проект Работа, Экология или Новое. В таких проектах быстро смешиваются несвязанные задачи.
2 Добавьте постоянные правила
В инструкции проекта внесите правила, которые действуют для всех задач внутри него. Укажите формат материалов, требования к стилю и порядок работы при нехватке данных.
Пример
Готовь обезличенные памятки и материалы для инструктажей. Пиши по-русски. Используй деловой стиль. Пиши короткими предложениями. Не добавляй факты, сроки, требования, обязанности и контакты, которых нет в исходных материалах. Если данных недостаточно, сначала перечисли вопросы для уточнения. Разделяй подтвержденные сведения, предположения и вопросы для проверки.
Проверяйте, чтобы инструкции не содержали данные конкретного предприятия, работников, договоров и текущих сроков.
3 Загрузите проверенные материалы
Добавьте в проект шаблоны и документы, на которые можно опираться при подготовке черновиков. Загружайте только материалы, которые вы проверили и разрешили использовать в работе.
Пример набора материалов
1. Шаблон памятки для сотрудников 2. Обезличенная форма листа ознакомления 3. Согласованный макет плаката 4. Мастер-промпт для подготовки черновика 5. Пример ранее согласованного текста
Внимание
Не загружайте документы с персональными данными, реквизитами, коммерческими условиями и другими сведениями, которые нельзя передавать в ИИ.
4 Создавайте чаты по задачам
Для каждой новой самостоятельной задачи создавайте отдельный чат внутри проекта. Название чата должно показывать тему и цель работы.
Примеры названий
Памятка по сбору материалов Инструктаж для новых сотрудников Обновление плаката для подразделения
Продолжайте прежний чат, если дорабатываете тот же документ. Так сохранятся согласованные формулировки, комментарии и история правок.
5 Поддерживайте порядок
Раз в месяц просматривайте материалы и чаты проекта. Удаляйте дубли. Обновляйте шаблоны. Переносите в архив завершенные рабочие ветки. Проверяйте, что в проекте не остались устаревшие версии памяток и материалы с чувствительными данными.
Если новая задача не связана с темой проекта, создайте для нее другой проект.
Лайфхак
Один проект - одна повторяющаяся рабочая тема. Это помогает быстро находить нужный шаблон и не смешивать контекст разных задач.
Проект помогает не повторять постоянные правила, хранить рабочие материалы в одном месте и быстрее находить нужные чаты.
