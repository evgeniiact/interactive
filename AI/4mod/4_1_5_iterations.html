Подготовьте макет из согласованного текста
Текстовый ИИ выделит данные для плаката и составит запрос для графической модели. Графическая модель создаст визуальную основу. Точный текст вы добавите вручную в редакторе.
Алгоритм
  1. Возьмите подготовленный фрагмент согласованного текста.
  2. Попросите текстовый ИИ выделить заголовок, действия, запреты и контакт.
  3. Проверьте, что ИИ не добавил новых правил.
  4. Попросите составить промпт для графической модели.
  5. Доработайте композицию коротким уточняющим запросом.
  6. Добавьте текст вручную в PowerPoint.
Учебный фрагмент
В административном корпусе организуют сбор бытовых батареек. Для сотрудников подготовили информационный материал. В контейнер принимают [перечень допустимых элементов]. Не принимают [перечень предметов, не входящих в учебный сценарий]. Текст плаката должен содержать согласованные правила и контакт [контакт для вопросов].
Промпт для текстового ИИ
Ты помогаешь подготовить учебный информационный плакат. Используй только сведения из текста ниже. Не добавляй правила, запреты, сроки, контакты, маркировку и другие сведения от себя. Если в тексте нет нужной информации, поставь поле [нужно уточнить]. Сначала подготовь: - заголовок плаката; - что можно сдавать, только если это указано в тексте; - что нельзя сдавать, только если это указано в тексте; - контакт для вопросов, только если он указан в тексте. Затем составь промпт для графической модели. В промпте: - опиши только предметы и действие из исходного текста; - задай вертикальный формат А4; - оставь свободное место сверху для заголовка; - не добавляй текст, буквы, цифры, логотипы и маркировку. Исходный текст: [вставьте согласованный учебный фрагмент]
🔍 Проверка
Текстовый ИИ готовит структуру и промпт. Сравните его ответ с исходным текстом до передачи запроса графической модели.
