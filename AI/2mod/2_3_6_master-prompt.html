В инструкцию для аккаунта - глобальные правила

  • Профессия и общий контекст: кто вы и в какой сфере работаете. Подходит всем чатам.
  • Стиль и тон общения: деловой, партнерский, без поучений. Задается один раз.
  • Профессиональная терминология: аббревиатуры НВОС, ИЗАВ, ПЭК, КЭР без расшифровки.
  • Безопасность: запрет на реальные ФИО, реквизиты, координаты объектов. Использование заглушек.
  • Запрет на выдумку: не придумывать номера нормативных актов, сроки и штрафы.

В мастер-промпт - правила для конкретного чата

  • Узкая роль нейросети: помощник по письмам, редактор памяток, аналитик рисков.
  • Алгоритм ответа: структура из трех шагов, порядок выдачи информации.
  • Формат результата: таблица, список, черновик письма - меняется от задачи к задаче.
  • Специфические ограничения: запрет предлагать закупки, не расширять тему диалога.
  • Контекст работы: период, площадка, направление - актуальны только для этого чата.
Главное правило. Проверьте каждый блок вопросом: это правило работает во всех новых чатах? Да - в инструкцию для аккаунта. Нет - в мастер-промпт для чата. Локальный мастер-промпт имеет приоритет над глобальными настройками аккаунта.
