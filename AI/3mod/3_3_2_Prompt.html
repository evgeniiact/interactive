Промпт для текстовой нейросети
Скопируйте запрос в текстовую нейросеть. Нейросеть подготовит план презентации из шести слайдов по исходному тексту.
Промпт
Ты методист инструктажей для работников промышленного предприятия. Подготовь план презентации по исходному тексту. Аудитория: новые работники участка резки стекла, участка контроля качества и склада готовой продукции. Тема: раздельное накопление отходов на заводе по производству стеклопакетов. Цель: научить работников раздельно собирать стеклобой, картон, пленку, поврежденную упаковку и пустые пластиковые бутылки. Объяснить действия при переполнении контейнера. Формат: шесть слайдов. Для каждого слайда подготовь короткий заголовок и до трех тезисов. Один слайд - одна мысль. Используй только сведения из исходного текста. Не добавляй сроки, коды отходов, классы опасности, номера документов, адреса, ФИО, телефоны, названия подрядчиков и правила для ремонтной службы. Исходный текст: [вставьте учебный текст или обезличенный фрагмент локальной инструкции]
Совет
Сохраните промпт в отдельном файле. Когда обновите локальную инструкцию, замените только исходный текст, а структуру запроса оставите без изменений.
